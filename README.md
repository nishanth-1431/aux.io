# 🎧 aux.io

> A free, open-source, and ad-free music listening platform built from scratch with Java.

## 📌 About

**aux.io** is a beginner-friendly music player web application designed to provide a simple and seamless music listening experience without advertisements or paid subscriptions.

The platform will provide access to openly available music and allow authors to submit their own music for review and approval before it becomes publicly available.

## 🎯 Project Goal

The goal of aux.io is to build a real-world Java web application while learning and applying:

* Core Java
* Java Servlets
* MVC Architecture
* JDBC
* SQL
* HTML & CSS
* Maven
* Git & GitHub

## 🚧 Project Status

**Currently:** Phase 1 — Product & Requirements

The project is being developed incrementally as a Project-Based Learning (PBL) project.
